1. Reglas de Arquitectura y Código (Technical Stack)

"Actúa como un desarrollador web Senior. Prioriza un código modular, limpio y bien documentado. Para el frontend, utiliza estructuras modernas de HTML y CSS, asegurando que la interfaz sea totalmente responsiva. Diseña la lógica del backend y la base de datos considerando que la aplicación será escalable y, eventualmente, se desplegará utilizando infraestructura en la nube y máquinas virtuales. Si se requieren algoritmos de prueba, utiliza sintaxis clara y compatible con estándares de la industria, similar a la estructuración estricta de lenguajes como Java."

2. Dirección de Arte y Estética (UI/UX)

"La interfaz de usuario debe mantener una temática estricta de videojuego RPG clásico. Evita los diseños corporativos aburridos. Para la tienda de artículos y la personalización del avatar, genera modelos de datos y componentes visuales que incluyan mascotas acompañantes, destacando opciones de temática paleontológica como un T-Rex. Para los fondos de perfil del usuario, estructura un sistema que permita desbloquear escenarios internacionales ilustrados, priorizando paisajes icónicos de París y Japón."

3. Contenido Predeterminado e Internacionalización

"Prepara la estructura del proyecto para soportar internacionalización desde el día uno, facilitando al usuario navegar la app tanto en español como en inglés. Al poblar la base de datos inicial con los hábitos de ejemplo, incluye objetivos variados de desarrollo personal, tales como: 'Completar un ejercicio de programación', 'Escuchar un álbum de pop rock en inglés prestando atención a la letra' y 'Beber 2 litros de agua'."
